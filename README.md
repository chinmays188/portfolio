# Chinmay Shandilya — Product Portfolio

Live site: **https://pschinmayshandilya.netlify.app**

A personal portfolio built as a living product: impact stories from MakeMyTrip and Zoomcar, the side projects I'm building with AI, and a public "life roadmap" in To Do / In Progress / Shipped form.

## Pages

| File | What it is |
|------|------------|
| `index.html` | Home — intro, impact highlights, North Star, Solution Space projects, contact |
| `persona.html` | Background, values and personal philosophy |
| `road-map.html` | Life roadmap board (To Do / In Progress / Shipped) |

Shared styling lives in `styles.css` and behaviour (theme toggle, share menu, project scroller, roadmap drag-and-drop) in `script.js`.

## How it's built and deployed

- Plain HTML, CSS and JavaScript — no framework, no build step.
- Built with AI assistance (prompting and "vibe coding").
- Hosted on Netlify, connected to this repository: every push to `main` deploys to the live site within seconds.

## Making a change

1. Edit the files (open any `.html` file in a browser to preview locally).
2. Commit and push to `main`.
3. Check the live site — Netlify publishes automatically.

Keep images small: photos are shown at about 250px wide, so 1200px on the long edge is plenty.
